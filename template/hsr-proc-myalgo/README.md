# hsr-proc-myalgo

Заготовка пакета с алгоритмом обработки для HyperSpectRus. Скопируйте каталог к себе и переименуйте.

## Переименование

| Что | Где | На что |
|---|---|---|
| Название пакета | `pyproject.toml`, `name` | `hsr-proc-<ваше>` |
| Каталог модуля | `src/hsr_proc_myalgo` | `src/hsr_proc_<ваше>` |
| Точка входа | `pyproject.toml`, раздел `[project.entry-points."hsr_proc.processors"]` | `<ваше> = "hsr_proc_<ваше>:MyProcessor"` |
| Имя реализации | `processor.py`, поле `name` | попадает в карточку сеанса, должно быть уникальным |
| Имя пакета в тестах | `tests/test_conformance.py`, `distribution` | `hsr-proc-<ваше>` |

Имя реализации между версиями больше не меняется: по нему отличают, каким алгоритмом посчитан сеанс.

## Свой репозиторий

Раскомментируйте `[tool.uv.sources]` в `pyproject.toml`: контракт и набор проверок будут ставиться из общего репозитория по тегу версии контракта. Затем:

```bash
uv sync
uv run hsr-proc-check
```

Заготовка возвращает пустые карты правильного вида: обязательный уровень проверок проходит, числовой падает. Так и должно быть, пока расчёт не написан.

## Что писать

Ищите пометки `ЗДЕСЬ` в `src/hsr_proc_myalgo/processor.py`. Порядок шагов такой:

1. яркости переводятся в оптическую плотность;
2. по матрице коэффициентов восстанавливаются карты концентраций;
3. по картам гемоглобина строится карта THb;
4. по карте THb выделяется область поражения;
5. считаются средние концентрации в поражении и в коже и их отношение.

Подробности - в [CONTRACT.md](../../CONTRACT.md). Прочитайте его до того, как писать расчёт.

## Перед отправкой

```bash
uv run pytest                        # ваши проверки и приёмочные
uv run hsr-proc-check --report приёмка.md
uv run hsr-proc-run --synthetic --out out   # посмотреть на карты глазами
```

К передаче прикладываются колесо `.whl`, отчёт приёмки и описание изменений.
