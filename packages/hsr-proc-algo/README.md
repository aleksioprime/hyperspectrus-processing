# hsr-proc-algo

Пакет алгоритма обработки: восстановление концентраций хромофоров по спектральному кубу.

## Алгоритм расчёта

Прибор снимает один участок кожи в нескольких спектрах. Хромофоры по-разному поглощают свет разных длин волн, поэтому по яркостям одного пикселя на всех кадрах серии можно восстановить, сколько в нём каждого вещества.

1. **Оптическая плотность.** Яркость каждого пикселя переводится в `-log10` от яркости. Плотность связана с концентрацией поглотителя линейно, и это превращает задачу в систему линейных уравнений. Яркость ограничена снизу: логарифм нуля обратился бы в бесконечность.
2. **Концентрации хромофоров.** Система решается по матрице коэффициентов перекрытия из справочника. Спектров больше, чем хромофоров, поэтому решение ищется методом наименьших квадратов - сразу для всех пикселей кадра одним вызовом.
3. **Карта THb.** Общая концентрация гемоглобина - сумма модулей `HbO2` и `Hb`. Справочник ведёт пользователь рабочего места, и нужных обозначений в нём может не оказаться: тогда THb считается из того, что есть, а поле `notes` объясняет врачу, из чего именно.
4. **Область поражения.** Карта THb сглаживается гауссовым ядром и делится порогом Отсу на очаг и здоровую кожу. Сглаживание нужно, чтобы пиксельный шум не дробил очаг на отдельные пятна.
5. **Показатели.** Средние THb внутри очага и снаружи и их отношение - коэффициент s. По нему врач видит динамику между сеансами.

## Как проверять

```bash
uv run hsr-proc-check hsr-proc-algo          # приёмка целиком
uv run pytest packages/hsr-proc-algo         # приёмка и собственные проверки пакета
uv run hsr-proc-run --synthetic --out out    # посмотреть на карты глазами
```

## Состав

| Файл | Назначение |
|---|---|
| `processor.py` | Расчёт концентраций и показателей |
| `segmentation.py` | Сглаживание и выделение области поражения |
| `conformance.toml` | Допуски приёмки и объявленные отступления |
| `tests/conftest.py` | Построение серии с заранее известным ответом |
| `tests/test_processor.py` | Проверка обратимостью: по известным концентрациям алгоритм обязан вернуть их же |
| `tests/test_segmentation.py` | Порог Отсу и сглаживание |
| `tests/test_conformance.py` | Приёмочный набор целиком |

Зависимости алгоритма объявляются здесь же: в контракт и в другие пакеты они не попадут.
