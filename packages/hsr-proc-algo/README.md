# hsr-proc-algo

Пакет алгоритма обработки: восстановление концентраций хромофоров по спектральному кубу. Это то место, где живёт расчёт.

Сейчас здесь тот самый расчёт, который работает в рабочем месте врача: перевод яркостей в оптическую плотность, решение системы по матрице коэффициентов, карта THb, выделение очага порогом Отсу и коэффициент s. С него и начинается исследование - он проходит приёмку целиком, поэтому любое изменение сразу видно на фоне рабочего поведения.

## Что менять

`processor.py` и `segmentation.py` - это и есть предмет исследования, правьте их свободно. Не трогайте только согласованное с приложением:

| Что | Где | Почему |
|---|---|---|
| Имя пакета, модуля, точка входа | `pyproject.toml` | по ним рабочее место находит реализацию |
| `name = "algo"` | `processor.py` | по нему рабочее место выбирает расчёт |

Поле `version` поднимается при любом изменении расчёта: оно попадает в карточку сеанса, и по нему сравнивают результаты. Назад версия не идёт.

## Как проверять

```bash
uv run hsr-proc-check hsr-proc-algo          # приёмка целиком
uv run pytest packages/hsr-proc-algo         # приёмка и собственные проверки пакета
uv run hsr-proc-run --synthetic --out out    # посмотреть на карты глазами
```

Допуски приёмки лежат в `src/hsr_proc_algo/conformance.toml` и едут вместе с пакетом. Для расчёта на другой математической модели там же объявляются послабления и причина каждого.

## Состав

| Файл | Назначение |
|---|---|
| `processor.py` | Расчёт концентраций и показателей |
| `segmentation.py` | Сглаживание и выделение области поражения |
| `conformance.toml` | Допуски приёмки и объявленные отступления |
| `tests/test_processor.py` | Проверка обратимостью: по известным концентрациям алгоритм обязан вернуть их же |
| `tests/test_segmentation.py` | Порог Отсу и сглаживание |
| `tests/test_conformance.py` | Приёмочный набор целиком |

Зависимости алгоритма объявляются здесь же: в контракт и в другие пакеты они не попадут.
