# hsr-proc-base

Контракт обработки мультиспектральных серий: описание входных и выходных данных и реестр реализаций.

Главный исходник находится в
`hyperspectrus-processing/packages/hsr-proc-base`. Каталог с тем же именем в
репозитории `hyperspectrus` — зеркало: напрямую его не редактируют. После
изменения интерфейса исследователи повышают версию пакета, проверяют алгоритм и
передают согласованную копию в приложение. Команда запускается из корня
`hyperspectrus-processing`:

```bash
uv run python tools/sync_contract.py ../hyperspectrus
```

Как оформить, подключить и заменить пакет алгоритма, описано в корневом README
репозитория `hyperspectrus-processing`.

## Состав

| Модуль | Назначение |
|---|---|
| `models.py` | Спектральный куб, матрица коэффициентов перекрытий, параметры и результат |
| `contract.py` | Протокол `Processor` - единственное, что связывает алгоритм с рабочим местом |
| `registry.py` | Поиск реализаций среди точек входа, выбор по имени |
| `loading.py` | Сборка куба из файлов серии, снятой устройством |

Пакет не зависит ни от интерфейса, ни от базы данных: на вход поступают массивы и коэффициенты, на выход - карты и показатели. Выполняется только на рабочем месте врача - снимки пациентов не покидают компьютер.

Зависимости намеренно ограничены `numpy` и `pillow`; тяжёлые библиотеки объявляет у себя пакет с алгоритмом.

## Проверка подключения

```bash
uv run python -m hsr_proc
```
