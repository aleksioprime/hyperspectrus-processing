# Конфигурация спектров

`hsr-example.json` - главный исходник конфигурации модели `HSR-EXAMPLE`: длины волн, хромофоры и матрица перекрытий. Его редактируют и проверяют в этом репозитории вместе с алгоритмом и тестовыми сериями.

В `hyperspectrus` уходит точная копия файла:

```bash
uv run python tools/sync_reference.py ../hyperspectrus
```

После синхронизации файл находится в `hyperspectrus/references/hsr-example.json` и может быть загружен в рабочее место. Версию `reference_version` нужно менять при изменении коэффициентов.

Имя JSON-файла не выбирает настройки для конкретного расчёта. После загрузки рабочее место сохраняет справочник в базе. При обработке оно берёт модель прибора, которым снят сеанс, и строит матрицу из коэффициентов этой модели.

Текущие значения справочные и не учитывают реальные спектры светодиодов, чувствительность камеры и оптику. Для медицинской диагностики они непригодны.
